## 🌟 What GitLegacy Offers

### 🎨 1. GitHub Contribution Art Studio (`/tools/art-studio`)
Turn your 53-week $\times$ 7-day contribution graph into pixel-perfect artwork, retro gaming nostalgia, or custom typography:
- ✍️ **Custom Typography Engine**: Type any word or phrase with configurable letter spacing and column-nudging logic.
- 👾 **Iconic Preset Gallery**: 1-Click load classic pixel templates including *Pac-Man*, *Space Invaders*, *Mario 8-Bit*, *Tetris*, *"HIRE ME"*, and tech logos.
- 🖌️ **Cell-by-Cell Level Brush**: Draw, erase, or adjust commit intensity levels ($0$ to $4$) freehand directly on the 53-week matrix grid.
- ⚡ **1-Click Script Automation**: Export ready-to-run non-destructive commit automation scripts in **PowerShell** (`.ps1`), **Bash** (`.sh`), and **Python** (`.py`).

---

### 🛡️ 2. Developer Badge Studio (`/tools/badges`)
Design, aggregate, and export high-performance Shields.io developer badges for your GitHub Profile `README.md`:
- 🛒 **1-Click Stack Basket**: Pick badges across **Frontend**, **Backend**, **Databases**, **DevOps & Cloud**, and **Digital Marketing & SEO** (featuring *WordPress*, *SEO*, *Google Ads*, *Meta Ads*, *Analytics*, *CodeIgniter 3/4*, *Laravel*, *Next.js*, etc.).
- 📦 **Clean Profile HTML Output**: Export 1-click badge baskets as neatly formatted `<p align="center">` HTML grids that eliminate source code clutter on your GitHub profile.
- 🎨 **Multi-Style Selector**: Switch between 5 badge styles instantly (`plastic`, `for-the-badge`, `flat`, `flat-square`, `social`).
- 🛠️ **Custom Shields Generator**: Build personalized status badges with custom labels, messages, hex colors, and logo icons.

---

### 📊 3. Real GitHub History Visualizer (`/tools/history-visualizer`)
Render full multi-year GitHub contribution posters inspired by high-fidelity canvas generators:
- ⚡ **Real GitHub Live Fetch**: Enter any GitHub username to fetch real multi-year contribution history via `/api/user-contributions`.
- 🎨 **14 Vibrant Theme Palettes**: Includes *GitHub Classic*, *GitHub Dark*, *Halloween*, *Teal*, *Dracula*, *Pink*, *Sunny*, *Solarized Light/Dark*, *Panda 🐼*, and more.
- 📥 **Multi-Format Export**: 1-Click Retina DPI PNG poster download (`gitlegacy-[username]-github-contributions.png`), copy poster canvas directly to clipboard, or generate Markdown embed snippets.

---
