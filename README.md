## ✨ Key Product Features

### 🎨 1. 53-Week Pixel Art Canvas Studio
- **Precision Text & Pixel Matrix**: Spell out custom words, text patterns, or custom drawings across the 53-week x 7-day contribution grid.
- **Unified Column Nudging**: Nudge text patterns and manual pixel drawings in perfect synchronization across weeks.
- **Tightly Spaced Typography**: Custom character matrix engine supporting strict 1-column letter gaps and configurable word spacing.
- **Custom Overrides & Freehand Drawing**: Draw, erase, or adjust commit intensity levels (0 to 4) cell-by-cell.

### 🛡️ 2. Dynamic Profile SVG Badge Engine
Embed live, serverless SVG preview badges directly into your GitHub Profile `README.md` with auto-updating metrics:

```markdown
![My Git Canvas](https://gitlegacy.dev/api/badge?text=YOUR_TEXT&year=2026&theme=github-dark)
```

- **Dynamic Username Route**: `https://gitlegacy.dev/api/u/username.svg`
- **Fully Customizable**: Tweak text, target year, color themes, and card/compact layout styles via simple URL query parameters.

### 🖼️ 3. Multi-Format Social Media Banner Exporter
Export your 53-week contribution graph artwork as pixel-perfect, Retina DPI banners for developer social media:
- 🐦 **Twitter / X Header Banner**: $1500 \times 500$ px
- 💼 **LinkedIn Cover Banner**: $1584 \times 396$ px
- 📸 **Instagram Post Graphic**: $1080 \times 1080$ px

### 👾 4. Pre-Made Template Gallery
Select from iconic ready-to-load contribution artwork templates:
- **Gaming Classics**: *Space Invaders*, *Pac-Man*, *Mario 8-Bit*, *Tetris Blocks*
- **Career & Hireability**: *"HIRE ME"*, *"OPEN TO WORK"*, *"AVAILABLE"*
- **Tech Stack Logos**: *Python*, *JavaScript*, *React*, *Rust*, *Go*
- **Signature Patterns**: *"LORD"*, *"GITHUB"*, *"GIT LEGACY"*, *"CODE 2026"*

### ⚡ 5. 1-Click Commit Automation Generator
Export non-destructive commit automation scripts ready to apply to your backdated repository:
- **PowerShell** (`.ps1`) for Windows developers
- **Bash** (`.sh`) for macOS / Linux environments
- **Python** (`.py`) standalone script

## 🚀 Local Development Setup

To run GitLegacy locally on your machine:

```bash
# Clone repository
git clone https://github.com/Sukhman369/githublegacy.git
cd githublegacy

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to launch the contribution planning studio.
